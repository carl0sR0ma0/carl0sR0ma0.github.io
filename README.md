# carl0sR0ma0.github.io

Portfólio profissional de Carlos Romão — Desenvolvedor Full Stack.

## Stack

- Next.js 16 (App Router, static export)
- TypeScript
- Tailwind CSS v4
- Framer Motion

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Gera a pasta `out/` com o site estático.

## Deploy

Push na branch `main` dispara o GitHub Actions que faz build e deploy automático para GitHub Pages.
